- #常用工具 [CookieCloud](https://github.com/easychen/CookieCloud/blob/master/README_cn.md) 是一个和自架服务器同步Cookie的小工具，可以将浏览器的Cookie及Local storage同步到手机和云端，它内置端对端加密，可设定同步时间间隔。
	- 如何通过chrome插件获取网站cookie
		- `manifest.json`
		  ```json
		  {
		    "name": "__MSG_appTitle__",
		    "description": "__MSG_appDesc__",
		    "default_locale": "zh_CN",
		    "permissions": [
		      "cookies", // cookies权限
		      "tabs",
		      "storage",
		      "alarms",
		      "unlimitedStorage"
		    ],
		    "host_permissions": [
		      "<all_urls>"
		    ],
		    "version": "0.3.0"
		  }
		  ```
		- `extension/function.js`文件中
		  ```javascript
		  /**
		   * 从浏览器获取所有cookie
		   * @returns object
		   */
		  async function collect_cookie_from_browser()
		  {
		      const cookies_raw = await chrome.cookies.getAll({});
		      // ... (代码有删减，保留核心逻辑)
		      const cookies = {};
		      for( const item of cookies_raw )
		      {
		          // 忽略 httpOnly 的 cookie
		          if( item.httpOnly ) continue;
		          const domain = item.domain.replace(/^./, '');
		          if( !cookies[domain] )
		          {
		              cookies[domain] = [];
		          }
		          cookies[domain].push(item);
		      }
		      return cookies;
		  }
		  ```
			- **`if( item.httpOnly ) continue;`**
				- 这里有一个判断，如果 Cookie 是 `httpOnly` 的，就跳过。`httpOnly` 是一种安全设置，表示该 Cookie 不能被客户端脚本（如 JavaScript）访问。虽然插件的 API 可以读取到它们，但 `CookieCloud` 的作者在这里选择忽略它们，可能是因为这类 Cookie 主要用于服务器验证，同步到其他地方意义不大或存在安全风险。
			- 数据处理和归类
				- `const domain = item.domain.replace(/^./, '');`
				- `if( !cookies[domain] ) { cookies[domain] = []; }`
				- `cookies[domain].push(item);`
				- 这几行代码的作用是按域名对 Cookie 进行分组。例如，所有 `google.com` 的 Cookie 会被放在同一个数组里，所有 `github.com` 的 Cookie 会被放在另一个数组里，最终形成一个以域名为键、Cookie 列表为值的对象，方便后续处理（加密和上传）。
