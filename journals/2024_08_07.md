			- ```go
			  func (w *World) AddEntity(e Identifier) {
			  	if w.sysIn == nil {
			  		w.sysIn = make(map[reflect.Type][]reflect.Type)
			  	}
			  	if w.sysEx == nil {
			  		w.sysEx = make(map[reflect.Type][]reflect.Type)
			  	}
			  
			  	search := func(i Identifier, types []reflect.Type) bool {
			  		for _, t := range types {
			  			if reflect.TypeOf(i).Implements(t) {
			  				return true
			  			}
			  		}
			  		return false
			  	}
			  	for _, system := range w.systems {
			  		sys, ok := system.(SystemAddByInterfacer)
			  		if !ok {
			  			continue
			  		}
			  
			  		if ex, not := w.sysEx[reflect.TypeOf(sys)]; not {
			  			if search(e, ex) {
			  				continue
			  			}
			  		}
			  		if in, ok := w.sysIn[reflect.TypeOf(sys)]; ok {
			  			if search(e, in) {
			  				sys.AddByInterface(e)
			  				continue
			  			}
			  		}
			  	}
			  }
			  ```

		- Component
			- 提出了Free组件和Disposable组件
				- Free组件，通常可作为一些临时数据的载体与多个系统共享。
				  比如，客户端通过网络上行的移动指令，在实际的开发中往往需要将这些指令缓存起来，多个指令同时处理。
				- Disposable(一次性的)组件，它是一次性组件，会在每帧结束后清理。
				  假设我们需要获取新增的Entity，可以在创建Entity时，同时添加Disposable组件， 在Update中获取该Disposable组件集合，从而获取新增的Entity。
				- FreeDisposable组件，Free组件与Disposable组件的结合体，它是一次性的游离态组件，会在每帧结束后清理。
			- 通过 GetComponent 获取指定Entity的指定Component
			  `c := ecs.GetComponent[TestComponent1](entity)`
