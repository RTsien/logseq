	- 有效阅读的速度是有限的。消除默读、增加阅读有效视觉范围（视觉定影，fixation）等速度方法被证明是伪科学。即使读得快，理解和记忆效率仍然存在瓶颈。
	  logseq.order-list-type:: number
	- 想提高阅读专注度，设定一个简易目标（量+时间）仍然是有效的方法。💡目标感是提升专注度的有效方法，能够及时从思维漫游拉回到正轨。
	  logseq.order-list-type:: number
	- 重点花太多会让人产生已经记住的错觉，而且会降低阅读速度。利用少量标记，有助于快速进入后续阅读和回顾即可。
	  logseq.order-list-type:: number
	- 💡提炼笔记是帮助理解和记忆的法宝
	  logseq.order-list-type:: number
	- sq3r法，预习-提问-阅读-背诵-回顾。不用严格套这个流程，💡**[[带着问题]]去阅读+做笔记+适当的回顾**即可。
	  logseq.order-list-type:: number
