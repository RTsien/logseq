- 如果容器的环境变量依赖configmap的key，且key不存在时，容器将无法启动（CreateContainerConfigError）。利用该特性可以通过修改configmap的（逐个添加）key来控制容器启动顺序。 ((6588559f-5631-4066-af12-c13d99e83d13)) #容器启动顺序 #K8s
	- ```yaml
	  spec:
	    template:
	      spec:
	        containers:
	        - name: container-0
	          env:
	          - name: b0
	            valueFrom:
	              configMapKeyRef:
	                key: b0
	                name: barrier
	                optional: false
	        - name: container-1
	          env:
	          - name: b1
	            valueFrom:
	              configMapKeyRef:
	                key: b1
	                name: barrier
	                optional: false
	  ```
	- ```yaml
	  apiVersion: v1
	  kind: ConfigMap
	  metadata:
	    name: barrier
	  data:
	    p0: "true"
	    p1: "true"
	  ```
