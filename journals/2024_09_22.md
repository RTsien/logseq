- 查看mongo的分片信息 [from Monica](https://monica.im/share/chat?shareId=HXYYuqVHJWOdwJaU&locale=zh_CN)
	- 1. 使用 `db.collection.getShardDistribution()` 方法：
		- ```javascript
		   db.yourCollectionName.getShardDistribution()
		   ```
		- 这个命令会显示集合的分片分布情况，包括 shard key。
	- 2. 查看集合的索引信息：
		- ```javascript
		   db.yourCollectionName.getIndexes()
		   ```
		- Shard key 通常会作为索引存在，查看索引可以帮助识别 shard key。
	- 3. 使用 `config` 数据库：
		- ```javascript
		   use config
		   db.collections.find({ "_id" : "yourDatabaseName.yourCollectionName" }, { key: 1 })
		   ```
		- 这会直接从配置数据库中查询 shard key 信息。
	- 4. 使用 `sh.status()` 命令：
		- ```javascript
		   sh.status()
		   ```
		- 这个命令会显示整个分片集群的状态，包括每个集合的 shard key。
	- 5. 对于 MongoDB 4.2 及以上版本，可以使用 `listShards` 命令：
		- ```javascript
		   db.adminCommand( { listShards: 1 } )
		   ```
		- 这会列出所有分片的信息，包括 shard key。
