			- ```mermaid
			  graph TD
			      A[开始] --> B[获取当前时间 now]
			      B --> C[预加载玩家基础数据]
			      C --> D{遍历所有活动配置}
			      
			      D -->|是| E[检查活动入口是否匹配]
			      E -->|是| F[检查活动是否有效]
			      F -->|是| G[添加到 activeActIDs]
			      
			      D -->|遍历结束| H[对 activeActIDs 排序]
			      H --> I[获取所有活动名称 activeActNames]
			      I --> J[批量加载所有活动数据]
			      
			      J --> K{遍历所有活动}
			      K -->|是| L[处理单个活动状态流 ProcessActFlow]
			      L --> M{活动状态是 OPENING?}
			      M -->|是| N[添加到 openingActs]
			      
			      K -->|遍历结束| O{遍历 openingActs}
			      O -->|是| P[检查活动是否自定义显示]
			      P -->|显示| Q[添加到 newOpeningActs]
			      
			      O -->|遍历结束| R[返回 newOpeningActs]
			      R --> S[结束]
			      
			      %% 样式
			      classDef default fill:#f9f,stroke:#333,stroke-width:2px;
			      classDef process fill:#bbf,stroke:#333,stroke-width:2px;

			      classDef inputoutput fill:#9f9,stroke:#333,stroke-width:2px;
			      
			      class A,S inputoutput;
			      class E,F,M,P decision;
			      class B,C,D,G,H,I,J,K,L,N,O,Q,R process;
			  ```
