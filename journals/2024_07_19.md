- 如何找到部件到剧情的关系 #RED/zonesvr #RED/海域探险
	- 某个状态下，计算哪个剧情优先级更高
	- ```go
	  // 得到该部件的事件配置
	  func (pc *ParsedConfig) GetComponentMatchPlotRules(componentID, stateValue int64) []*MatchPlots {
	  	cInfo := pc.ComponentConf.ComponentIDToInfo[componentID]
	  	if cInfo == nil {
	  		return nil
	  	}
	  	return cInfo.MatchPlotsRules[stateValue]
	  }
	  ```
	- 剧情表里的match_plots就是剧情规则
