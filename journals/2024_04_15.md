	- 捞数据
	  logseq.order-list-type:: number
		- 以下例子是用python捞几个db(all_dbs )的index_information
		  ```python
		  kubectl run ubuntu-node --restart=Never --rm -i --tty --image python -- /bin/bash
		  
		  然后运行下面代码：
		  #!/usr/bin/python3
		  import pymongo
		  
		  mongo_addr = "mongodb-mesh.red-system"
		  mongo_port = 27017
		  # 所有的db名字，根据实际填写
		  all_dbs = ['infosvr-0719-stable', 'guildsvr-stable', 'mailsvr-stable', 'rank-stable', 'roomsvr-stable',
		             'scenesvr-stable']
		  
		  if __name__ == '__main__':
		      client = pymongo.MongoClient(mongo_addr, mongo_port, maxPoolSize=50)
		      coll_dict = dict((db, [collection for collection in client[db].collection_names()])
		                       for db in all_dbs)
		      for key in coll_dict:
		          for coll_entry in coll_dict[key]:
		              # key: db名字， coll_entry: collection名字
		              print(key, "|", coll_entry, "|", client[key][coll_entry].index_information())
		  ```
