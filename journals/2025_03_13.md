- iPhone快捷指令学习系统 #[[自动化]] #[[英语]] created by #cursor
	- 1. 每日词汇学习提醒
		- 早间词汇学习
			- 触发条件：每天早上7:00
			- 执行动作：
				- 打开 Anki 应用
				- 播放学习音乐（可选）
				- 显示今日待学单词数
				- 完成后记录到 Day One
		- 晚间词汇复习
			- 触发条件：每天晚上9:00
			- 执行动作：
				- 打开 Anki 复习界面
				- 统计今日学习数据
				- 记录到 Logseq
	- 2. 听力训练助手
		- 通勤听力训练
			- 触发条件：连接 AirPods 或开启导航
			- 执行动作：
				- 自动播放订阅的英语播客
				- 打开语音识别
				- 记录关键词到备忘录
		- 新闻听力练习
			- 触发条件：每天中午12:00
			- 执行动作：
				- 下载 BBC/CNN 最新新闻
				- 生成字幕文件
				- 保存到学习文件夹
	- 3. 口语练习助手
		- 晨间朗读训练
			- 触发条件：闹钟响起后
			- 执行动作：
				- 随机选择一篇文章
				- 开启录音
				- 完成后对比原音频
		- 录音复盘工具
			- 触发条件：手动启动
			- 执行动作：
				- 录制口语练习
				- 通过 OpenAI API 转写文字
				- 分析发音问题
				- 生成改进建议
	- 4. 阅读写作助手
		- 技术文档阅读
			- 触发条件：指定时间或手动
			- 执行动作：
				- 从预设源获取文章
				- 生成生词表
				- 添加到 Anki
		- 写作练习提醒
			- 触发条件：每周日晚上
			- 执行动作：
				- 提供写作主题建议
				- 设置写作计时
				- 完成后通过 GPT 审核
	- 5. 学习追踪系统
		- 每日数据统计
			- 触发条件：每天晚上10:00
			- 执行动作：

				- 统计听力训练时长
				- 汇总口语练习次数
				- 生成日报发送到 Logseq
		- 周报生成器
			- 触发条件：每周日晚上
