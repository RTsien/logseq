- [[ssh]]登录的时候选择[[shell]]类型。再扩展一下：ssh进入终端交互模式的时候，可以提前执行命令 #linux #wsl #zsh
	- ```bash
	  alias dev='ssh root@9.134.0.156 -p 36000 -t /bin/zsh'
	  ```
	  如果使用了 nix，直接填`-t zsh`会调用 nix 的 zsh，输入中文会显示`<FFFFFFFF>`乱码
	  
	  根据`PATH`：`/root/go/bin:/root/.nix-profile/bin:/nix/var/nix/profiles/default/bin:/root/miniconda3/envs/cli/bin:/root/miniconda3/condabin:/usr/share/Modules/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/root/.ft:/root/bin:/root/.ft`
	  和`which zsh`，可以找到zsh默认是指向了`~/.nix-profile/bin/zsh`
	  
	  把 `~/.nix-profile/bin/zsh`复制到`/bin/zsh`，然后从/bin/zsh启动一样是乱码，这样相当于排除了配置文件的差异。暂且认为是~/.nix-profile/bin/zsh二进制本身的问题吧。
	  
	  不过在/bin/zsh里面执行~/.nix-profile/bin/zsh是能正常输入中文的
