- 通过ssh远程执行命令 #shell #ssh #linux
  id:: 64c92c03-5246-4caa-9f6c-c3d27a6896a8
	- ```shell
	  sshpass -p password ssh -o StrictHostKeyChecking=no root@ip -p port 命令
	  ```
	- 如果执行超时，打印超时ip
		- ```shell
		  if timeout 10 sshpass -p password ssh -o StrictHostKeyChecking=no root@ip -p port 命令 ; then echo done $ip; else echo timeout $ip; fi
		  ```
