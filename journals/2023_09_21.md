- 安装[[lxcfs]]的时候报错缺失libtinfo.so.5
	- ln -s /usr/lib64/libtinfo.so.6.1 /usr/lib64/libtinfo.so.5
- 安装[[lxcfs]]参考文章[src](https://km.woa.com/articles/show/448318)
	- `yum install -y fuse-libs`
	- ```
	  # clone lxcfs-admission-webhook(测试时使用版本为a875fad6647bb2c24aed067d186d341be099afa9)
	  git clone https://github.com/denverdino/lxcfs-admission-webhook
	  
	  cd lxcfs-admission-webhook
	  
	  # 替换为腾讯镜像仓库
	  sed -i "s|registry.cn-hangzhou.aliyuncs.com/denverdino|ccr.ccs.tencentyun.com/lxcfs|g" deployment/*.yaml
	  
	  # 让lxcfs组件运行在lxcfs namespace，而不是default
	  sed -i "s|deployment/webhook-create-signed-cert.sh|deployment/webhook-create-signed-cert.sh --namespace lxcfs |g" deployment/*.sh
	  sed -i "s|kubectl|kubectl -n lxcfs|g" deployment/*.sh
	  sed -i "s|namespace: default|namespace: lxcfs|g" deployment/*.yaml
	  
	  #创建lxcfs namespace
	  kubectl create ns lxcfs
	  ```
	- `kubectl -n lxcfs apply -f deployment/lxcfs-daemonset.yaml`
	- `deployment/install.sh`
