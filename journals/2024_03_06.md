- [[helm]]ConfigMap and Secrets utility functions
	- （在Helm 2.0.2及后续版本可用）
	- 把文件内容放入配置映射和密钥是很普遍的功能，为了运行时挂载到你的pod上。为了实现它，我们提供了一些基于`Files`类型的实用方法。为了进一步组织文件，这些方法结合`Glob`方法使用时尤其有用。使用 [[Glob]]时的示例如下：
	  id:: 65e8557b-e56e-4321-bc3a-467376946f11
	- ```yaml
	  apiVersion: v1
	  kind: ConfigMap
	  metadata:
	    name: conf
	  data:
	  {{ (.Files.Glob "foo/*").AsConfig | indent 2 }}
	  ---
	  apiVersion: v1
	  kind: Secret
	  metadata:
	    name: very-secret
	  type: Opaque
	  data:
	  {{ (.Files.Glob "bar/*").AsSecrets | indent 2 }}
	  ```
