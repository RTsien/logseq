	- ```go
	  // nil is a predeclared identifier representing the zero value for a
	  // pointer, channel, func, interface, map, or slice type.
	  var nil Type // Type must be a pointer, channel, func, interface, map, or slice type
	  
	  // Type is here for the purposes of documentation only. It is a stand-in
	  // for any Go type, but represents the same type for any given function
	  // invocation.
	  type Type int
	  ```
	- 本质上是一个 `Type`类型的变量而已；而`Type`类型是基于`int`定义出来的一个新类型；
	- `nil`是一个预先声明的标识符，表示指针、通道、函数、接口、映射或切片类型的零值,并不是GO 的关键字之一。
		- 💡或者说nil 只是一个 Type 类型的变量而已。
	- nil使用注意事项
		- 不同类型的nil值占用的内存大小可能是不一样的，不同类型 nil 的指针值是一样的( 0x0)
			- ```go
			  package main
			  
			  import (
			  	"fmt"
			  	"unsafe"
			  )
			  
			  func main() {
			  	var arr []int
			  	var i interface{} = nil
			  	var num *int
			  	var p *struct{} = nil
			  
			  	fmt.Printf("%d %p\n", unsafe.Sizeof(arr), arr) //24 0x0
			  	fmt.Printf("%d %p", unsafe.Sizeof(i), i)       //16 %!p(<nil>)不是指针
			  	fmt.Printf("%d %p\n", unsafe.Sizeof(num), num) //8 0x0
			  	fmt.Printf("%d %p\n", unsafe.Sizeof(p), p)     //8 0x0
			  }
			  ```
			- 💡意思是这些指针性质的变量，在值是nil时，被认为是0地址
		- 不同类型的 nil 是不能比较的
			- ```go
			  package main
			  
			  import "fmt"
			  
			  func main() {
			  	var arr []int
			  	var num []int
			      //可以直接跟nil比较
			  	if arr == nil {
			  		fmt.Println("arr is nil")
			  	}
			      //两个不同类型的nil是无法比较的，报错。
			  	if arr == num {
			  		fmt.Println("arr == num")
			  	}
			  }
			  ```
