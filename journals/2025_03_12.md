- 今天终于搞定 iphone 使用 git 同步 logseq，并自由在 的 logseq app 里自由编辑。这种方案避免了直接使用 icloud 容易出现文件并发编辑冲突的问题。
  主要依赖的是 iphone 的 git app 「working copy」。缺点就是需要用到 199 元的 pro 功能。🤦‍♂️
  主要参考[这篇](https://github.com/CharlesChiuGit/Logseq-Git-Sync-101/wiki/For-iOS-iPadOS-users-(Working-Copy)): 
  > choose `> Link Repository to`, then choose `Directory`. 
  > Make sure your in `My iPhone/iPad` (I would suggest don't choose iCloud to avoid some syncing issue) > create a new sub-folder under the Logseq-icon one (I would suggest don't name the folder with the same name as your repo.) > click `Done`
