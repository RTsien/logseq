	- 长期记忆的形成
		- 前额叶皮质编码 - 到达海马体 - 生成更多神经递质增强信息 - 形成新的突触
		- 临时抱佛脚对考试不起作用，长期记忆的形成需要时间
		- 涉及高级心理功能时，比如分析和综合，需要时间间隔，使得新的神经连接得以巩固。当时间不足时，新的知识会取代旧的知识。
		- 必须把学习的时间间隔开来。
	- 海马体会根据信息的重要性释放不同水平的神经递质
		- 强烈的情感体验：有形的，可视的，不寻常的

			- Benedict Carey's book How We Learn
			  collapsed:: true
				- 记忆的两种能力：存储能力，检索能力
				- 理论来说，存储能力是不会减弱的
				- 但是检索能力会随着时间流逝
				- 间隔效应：记忆的检索能力越弱，回忆的难度越大，学习的进步就越大。No Pain No Gain。越努力回忆某事，回报就越大
				- 为了最大限度提高学习效率，找到将要忘记某件事的临界点。
				- 间隔重复技巧：增加每次复习的间隔时间
				- Leitner System：不同时间间隔的盒子放置抽认卡。比如 anki
				  collapsed:: true
					- 记忆有两种
					  collapsed:: true
						- 识别：当你接触到之前见过的信息时，回想起内容
						- **回忆**：不直接看信息，而是从记忆深处挖掘出来。这正是在考试和很多现实世界情景中必须做的。
					- **确保把注意力放在主动回忆上**：不要被动阅读笔记和ppt，要用它们来进行测验，或者根据记忆总结
					- 对于数学，物理和运动同样适用：把重点放到对实际问题的练习上，并切实运用所学的概念和公式。
				- 学习要工作一样，对大脑有所挑战。当挑战来临时，你会记得更多，学得更快。
