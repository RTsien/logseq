	- 定义
		- 是一种行为习惯——高效、有价值、自驱力；自主自发、有意识、强烈的意愿、多聊、不要怕尬聊；向上管理是下属的责任
		- 职业生涯是马拉松，帮助老板和组织成功；混职场就是混口碑，越往上走越是小圈子，爱惜自己的羽毛；

		- 预防性措施：向老板拆解方案的风险时间检查点，以及预防性措施，并且及时反馈。最大化保护组织利益。

	- 永远不要让老板成为最后一个听到坏消息的人

- 03 | 初窥门径：开发并运行你的第一个[[eBPF]]程序 [src](https://time.geekbang.org/column/article/481090) #《eBPF核心技术与实战》
	- bcc helloworld
		- ```python
		  #!/usr/bin/env python3
		  # 1) import bcc library
		  from bcc import BPF
		  
		  # 2) load BPF program
		  b = BPF(text='''
		  int hello_world(void *ctx)
		  { 
		      bpf_trace_printk("Hello, World!\\n");
		      return 0;
		  }
		  ''')
		  # 3) attach kprobe
		  b.attach_kprobe(event="do_sys_open", fn_name="hello_world")
		  # 4) read and print /sys/kernel/debug/tracing/trace_pipe
		  b.trace_print()
		  ```
	- bpf_trace_printk打印格式
		- ```bash
		  b' cat-10656 [006] d... 2348.114455: bpf_trace_printk: Hello, World!'
		  ```
		- cat-10656 表示进程的名字和 PID；
		- [006] 表示 CPU 编号；
		- d… 表示一系列的选项；
		- 2348.114455 表示时间戳；
		- bpf_trace_printk 表示函数名；
		- 最后的 “Hello, World!” 就是调用 bpf_trace_printk() 传入的字符串。
