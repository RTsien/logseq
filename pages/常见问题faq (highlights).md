summary:: QPilot is a platform developed by the QQ team that utilizes LLM technology for various tasks, including coding assistance and document Q&A. Users can create custom robots, access plugins, and integrate with messaging services like WeChat and QQ without coding. The platform is open for all employees, providing features like API access and tools for enhancing document Q&A quality.

- Highlights first synced by [[Readwise]] [[Apr 15th, 2025]]
	- iwiki 同个空间里的文档有不同的查看权限，有些文档不希望公开，怎么保证数据安全？
	  
	  出于 KISS （Keep it Simple and Sweet）的原则，QPilot 并不会继承 iWiki 的权限设置。如果你的文档空间里的文章有不同的查看权限，希望针对不同的人响应不同范围的内容，可以制作多个文档问答助手，每个助手分别索引不同权限级别的文档，并在制作的时候选择不同的公开范围。
	  
	  ![enter image description here#485px #195px](https://iwiki.woa.com/tencent/api/attachments/s3/url?attachmentid=3741892)
	  
	  例如，假如 QPilot 空间里有一些内部文档，我们不希望被其他团队的小伙伴问到，那么在制作 “[QPilot使用助手](https://qpilot.woa.com/home/chat?qpilot_id=148)” 的时候就要排除这些不公开的文档。如果这些材料对于我们QPilot 小团队而言又有问答的需求，则可以单独制作一个 “QPilot 使用助手-内部版” ，一同索引这些文档，并设置仅内部成员所在的组可见。 ([View Highlight](https://read.readwise.io/read/01jrjmxd4epv0dh4t1yc2ftacs))
